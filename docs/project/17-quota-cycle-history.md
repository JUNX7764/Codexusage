## 口径与不确定性

- 7d 是接口窗口类别，不等同日历周。历史从本机首次有效观测开始；首次 `resetAt - 7天` 仅是推算，之后首次观测时间也不冒充精确起点。结束时间保留观测区间，详情展示最后观测时刻。
- 同窗口截止时间容差 120 秒；异常回落或仅截止时间变化先待确认。正常到期及来源未知提前重置需两笔独立、稳定的新窗口样本；间隔 10–180 秒，新窗口读数不能在确认时回落。采样间隔超过 15 分钟且窗口变化归为缺口，不猜测丢失轮次数。
- 套餐与窗口同时变化时，稳定新套餐/窗口经第二笔独立样本确认后，旧段结束为 `unconfirmed`、新段标记开始未知和不完整；展示「套餐/额度变更」，不称自然到期或计算确定到期未用。
- 自然到期显示最后观测已用和“到期未用约”；主动用卡或来源未知提前重置显示“重置前剩余约”。缺口和套餐变更不显示确定到期未用；进行中显示当前剩余。无绝对分母，不跨轮把百分比相加当作 Token 或绝对浪费。
- 已过接口截止但仍返回旧窗口时展示「等待重置确认」和最后观测值，不按本机时钟自动生成新轮次。
- `reset` 为已确认新用卡事实，但仍需后续消费响应后启动的有效 7d 变化样本；`already_redeemed` 是幂等核对，即使携带原时间也不独立创建边界，且不覆盖同操作已确认 `reset`。没有 7d 变化不新建轮次。
- 数据源是已有的 7d 刷新响应，不额外联网；无效、乱序、过期账号或旧 generation 响应不入账。第三方 Tibo 不是个人用卡证据。

## 数据与故障边界

稳定账户 identity 经 `SHA256("quota-cycle-v1|" + identity)` 派生分区，文件位于 `~/Library/Application Support/CodexUsage/quota-history/<hash>/history-v1.json`；目录 0700、文件 0600。无稳定账户不落盘。文件不保存账户原始身份、凭据、卡片 ID、原请求 key 或原始响应；用卡操作仅存哈希。预览不创建真实仓库。

持久化版本为 1；解码检查数值、时间、ID、顺序和候选归属。损坏或未来版本不覆盖原文件；写失败保留内存状态并显示「历史未保存」，下次保存可重试。无变化观测经去重和五分钟心跳减少写入。模型、仓库和协调器可用 `python3 -m unittest discover -s tests -p 'quota_cycle_history_test.py' -v` 在临时目录验证。

父会话已在真实 AppKit 假数据窗口检查翻页、悬停移出恢复、选中、折叠重开、单步方向键和 Escape；连续键盘跨页另由原生事件回归覆盖。VoiceOver 实际朗读和真实账号长期采样未验证，不能用固定数据代替；详见 [验证记录](../verification/2026-11-12-quota-cycle-history.md)。
