# v1.1.0 开发与验收交接

基线 `a541133cc278c040d40b95b80f3c977e33d51fd2`（v1.0.18），开发分支 `codex/v1.1.0-usage-overview`。此分支供主会话验收；未合并、推送、打标签、发布、安装或替换运行中的应用。构建显示的 `v1.0.18-…` 来自实际 `git describe`，不是正式 v1.1.0 发行版本。

## 已实现

- 现有重置卡、Tibo、更新控制保留；其后依次为本机合并周期表、官方用量简析和可折叠工具明细。模型在周期行原位展开；来源边界记录在文档中。
- 官方账号累计与日桶通过原生只读 `GET /backend-api/wham/profiles/me` 获取，使用认证快照与 `ChatGPT-Account-ID`，响应前后核对身份和凭据。该查询不刷新凭据；沿用额度请求的 401 续期链路。
- 依据 OpenAI [backend-client 固定提交](https://github.com/openai/codex/blob/bbf57cec15bcc8b96ec96638d0e83c9d787d6919/codex-rs/backend-client/src/client.rs) 的 profile 请求和 app-server 的字段映射。2026-11-06 本机只读核验返回 200；累计及每日桶与 CLI 返回逐项相同，认证字段前后不变。个人用量及账号信息未写入文档。
- 图表与比较以源最新日期为终点；遵循[官方客户端固定版本](https://github.com/openai/codex/blob/2c502d8b3d382dd609179164f31396d95deee55c/codex-rs/tui/src/analytics/activity_chart.rs)对稀疏活动桶的显示，实际返回区间内部缺桶按零，区间外不外推。比较支持零基期和过期门控；虚构与真实数据走同一算法。
- 本机缓存按实际文件路径唯一归属，使用相同快照计算来源与模型；来源失败时标记部分数据，保持旧贡献；不存在旧值的失败来源显示 `--`。Pro／PROLITE 的单窗口兼容只针对特定合法旧格式，实际有效 5H 优先。

各工具的日志适配、订阅登录与官方汇总覆盖，见[用量来源兼容矩阵](14-compatibility-matrix.md)。

## 用户体验修订（2026-11-06）

删除统计范围入口；「用量简析」默认展开，可通过标题或箭头独立收起；累计与标签同排。工具周期仅在工具明细展开时位于标题右侧，选择与折叠分离并保留进程内状态。官方范围内稀疏零值、图表命中和 D 基准比较共用同一规则，真实／演示不使用不同开关。

本轮只读日期核验：日与七日比较的源日期范围均可计算；认证文件校验前后一致。此结果不包含个人用量，不能推断其他账号或后端后续行为。验收截图：[默认](../acceptance/v1.1.0-revised/default.png)、[展开](../acceptance/v1.1.0-revised/expanded.png)、[深色](../acceptance/v1.1.0-revised/dark.png)、[320pt](../acceptance/v1.1.0-revised/narrow.png)、[简析折叠](../acceptance/v1.1.0-revised/daily-collapsed.png)、[稀疏及范围外夹具](../acceptance/v1.1.0-revised/sparse.png)。这些为开发预览，截图中的版本为生成时的真实构建标识。

## 同机资源对照（单次、合成数据）

基线与开发版分别编译；使用 250 个假 Codex 和 250 个假外部 JSONL，同机依次运行。首次先扫基线，随后开发版；无文件变化再次扫描；再向同一外部文件追加一条记录。面板数字为假数据预览进程从启动、打开、截图到退出的整体值，包含固定预览等待。单位：耗时／CPU 为秒，RSS 为 MiB。

| 场景 | 基线：耗时 / user+sys / 峰值 RSS | 开发版：耗时 / user+sys / 峰值 RSS |
|---|---|---|
| 首扫 | 0.11 / 0.06 / 14.14 | 0.46 / 0.06 / 14.44 |
| 无变化 | 0.03 / 0.02 / 18.53 | 0.03 / 0.02 / 18.64 |
| 少量追加 | 0.03 / 0.02 / 18.95 | 0.04 / 0.03 / 19.02 |
| 面板启动和截图 | 0.96 / 0.29 / 114.53 | 0.98 / 0.29 / 117.19 |

两版扫描后的缓存文件大小均为 Codex 65,861 字节、外部 41,153 字节；`time -l` 在上述单次运行报告块输入／输出均为 0，不能据此推断真实磁盘读写量。结果受文件系统缓存、执行顺序及单次采样影响；首扫墙钟差异需要重复测试才能归因。未测真实长期驻留 RSS、独立面板开合 CPU、系统唤醒数、电量、其他 macOS 版本或多显示器；上下文切换数不等于唤醒数。[原始时间输出](../acceptance/v1.1.0/performance-raw.txt)。该对照使用开发中的同版统计代码，后续微调额度解析和缺失数据文案未重测。
