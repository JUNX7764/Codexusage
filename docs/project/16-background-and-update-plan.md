# 面板背景与更新说明实施计划

参考 KimiUsage v1.7.7，适配 CodexUsage 现有面板和更新器，完成后先供用户验收，不发布。

1. 增加纯色、经典毛玻璃、液态玻璃三种背景，页头切换并保存。默认纯色；液态玻璃需要 macOS 26+，旧系统回退经典毛玻璃；系统降低透明度时临时使用纯色。
2. 检查可安装 Release 时同时保留其说明。点击更新提示后在面板内展示目标版本、当前版本和可滚动说明，提供对应 Release 链接；取消或关闭面板不下载，确认后才启动原有更新器，目标版本和说明变化时拒绝旧确认。
3. 后续发布采用仓库内版本说明文件，避免自动生成的内部提交记录直接呈现给用户。缺失或空说明时阻止发布，已存在 Release 的说明不一致时停止。
4. 离线测试样式降级、说明提取及格式、更新确认和取消；运行现有构建、自检及脚本回归，使用假数据核对面板。系统版本差异和真实安装分别标注验证范围。

不推送、不合并、不创建 tag、不发布，也不替换当前安装应用，等待用户确认效果。
