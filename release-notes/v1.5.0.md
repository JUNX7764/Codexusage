## 新增
- 页头新增「···」面板设置菜单：「卡片显示与排序…」支持七张业务卡片的显示隐藏与上下排序，改动自动保存，并提供恢复默认布局；隐藏的卡片仍照常获取数据，全部隐藏时显示空态和恢复入口。
- 背景样式收进同一菜单的子菜单，纯色／经典毛玻璃／液态玻璃的选择行为与旧系统兼容规则不变。
- 打开卡片设置页自动接管键盘焦点：空格键直接切换复选框，不会误触菜单导致面板关闭；后台数据刷新不会打断设置页操作。

## 优化与修复
- 额度周期回顾改为单根额度槽：每轮一根居中的灰色上限槽，已用比例按该轮自身上限归一化从底部填充；0% 不绘制填充，100% 填满；图例更新为「已用 / 距上限 / 当前」。
- 用量简析的日环比与 7 日环比改为软色胶囊，保留涨跌方向配色与悬停说明；面板较窄时自动换为两行，数字不截断。
- 每日图悬停数值增加 320ms 缓动过渡：快速扫过时从当前显示值平滑重定向，首次显示、无数据和系统「减少动态效果」下立即到位；辅助功能值始终为目标准确值。
- 每日柱仅顶部微圆角、底部基线齐平；额度周期回顾图标改用时钟符号，与用量简析的柱状图标区分。
- 重置卡行的「过期」说明词并入日期同色展示，不再单独标色，避免误读为卡片已失效；72 小时内到期的卡名仍用语义色提示。
- 设置页「恢复默认卡片布局」「返回」「完成」使用系统圆角按钮，「完成」为回车默认键。

## 数据与兼容说明
- 卡片显示与排序保存在本机偏好，损坏或未知配置自动回退默认布局；隐藏卡片不减少数据获取，菜单栏与状态文件不受影响。
- 额度周期归一化口径不变：已用比例按各轮自己的上限计算，不同上限的轮次不按柱高直接比较。
- 继续支持 macOS 13 及以上、Apple Silicon 与 Intel；安装包为 universal 双架构，使用 ad-hoc 签名，未做 Developer ID 公证。
