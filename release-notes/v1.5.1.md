## 新增
- 「模型响应」卡片：支持今天、近 7 天、近 30 天切换，展示整体及各模型的端到端加权 tok/s、中位耗时和有效请求数；卡头可查看统计口径说明。
- 「缓存命中」卡片：展示同周期的整体及各模型缓存命中率、输入量和有效请求数；周期内没有缓存读取或写入记录时显示「—」，区分「没有缓存数据」与「0% 命中」。
- 两张卡片默认显示在面板末两位，可通过「···」菜单隐藏、排序或恢复默认；已有卡片布局会自动保留并补入新卡片。

## 修复
- Tibo 事件全部被过滤时显示「暂无等待生效的重置」，不再留下只有标题的空白卡片。
- 「退出」按钮文字在 hover 底色中居中显示。

## 数据与兼容说明
- 两张新卡片复用现有本机 Codex 会话扫描，不新增网络请求；原有「用量情况」的统计口径与数据管线不变。
- 响应耗时与 tok/s 均为端到端口径，包含 Prefill、首字及网络等待，不是纯生成速度，不能与其他工具的 decode tok/s 直接比较。仅统计耗时大于 0 且不超过 900 秒、输入大于 0 的有效记录。
- 继续支持 macOS 13 及以上、Apple Silicon 与 Intel；安装包为 universal 双架构，使用 ad-hoc 签名，未做 Developer ID 公证。
