## 改进
- 系统或显示器休眠时自动暂停刷新与外观对账定时器，唤醒后等网络就绪再补一次刷新；深色唤醒（Power Nap）与睡眠期间的网络事件不再重启定时器。空闲能耗更低，唤醒后数据自愈。
- 网络断开恢复或切换接口时，若存在错误或过期数据源自动补刷新，断网恢复后无需手动刷新。
- 面板增量刷新改为真正的逐项相等比较：数据无变化时不再整面板重建，定时刷新更平滑，滚动位置、展开状态与说明浮窗不再被打断。
- 面板关闭期间跳过面板模型构建，后台轮询 CPU 开销下降；菜单栏图标按状态去重渲染，深色壁纸/双屏下不再周期性空转重绘。
- 诊断状态写入去重：易变时间戳不再触发写盘，空闲时磁盘写入大幅减少；退出时最近额度观测完整落盘。
- 401 凭据轮换后，同轮失败的官方用量与重置卡请求自动用新凭据重试一次，不再持续显示「账号认证失效」。
- 使用重置卡后的刷新改为只拉额度与重置卡的定向刷新，更快且省电；手动刷新兜底从 20 秒放宽到 50 秒，弱网下不再过早复位也不会永久卡死。

## 修复与稳定性
- 关闭「开机自启」不再向运行中的应用发送终止信号，切换开关后应用保持运行；自启状态改为校验实际可执行路径，应用移动或重装后菜单不再误报；开启/关闭失败时明确弹窗报错。
- 更新器加固：更新进程异常退出立即报错并恢复按钮，不再永久卡在进度行；卡死 10 分钟兜底超时（睡眠不走表）；下载进度在滚动或拖拽菜单时不再停摆；更新检查失败只进 60 秒短冷却，开机瞬时断网不再抑制检查半小时；版本选择改为语义版本号最高，补丁版本不会被误判为降级。
- 凭据与网络安全：auth.json 原子写权限收紧为仅所有者可读写，并发的非凭据外部编辑不再被覆盖；网络请求收敛到无重定向、无 Cookie、2 MiB 上限的专用会话；刷新冷却改用单调时钟。
- 本机与外部用量扫描：活跃文件保留边界校验，原位同大小覆盖不再漏算；zstd 归档末块完整清排；符号链接去重；外部扫描状态缓存损坏时保留健康缓存，不再整缓存作废。
- 界面与无障碍：额度行带提示时不再被裁切；Esc 按层级关闭（口径说明 → 卡片设置 → 更新确认 → 面板）；「模型响应」口径浮窗不再残留孤儿实例；跨天或官方数据过期时每日图立即重建，凌晨不再显示昨天；禁用按钮可辨识；装饰元素退出 Tab 与 VoiceOver 循环；多屏下面板宽度正确。

## 数据与兼容说明
- 数据源与请求频率不变：额度、重置卡、Tibo、更新检查沿用原节奏，休眠期间暂停属预期行为；本机扫描口径不变。
- 继续支持 macOS 13 及以上、Apple Silicon 与 Intel；安装包为 universal 双架构，使用 ad-hoc 签名，未做 Developer ID 公证。
